# Hilton Santos - Portfolio

A single-scroll personal portfolio built with **Nuxt 4**, **Vue 3**, and **Nuxt UI**, deployed as
a serverless SSR app on **Vercel**. The whole site lives on one page: full-viewport sections for
Hero, Experience, Projects, and Contact, chained together with GSAP-driven scroll snapping, and
available in English and Portuguese.

## Tech stack

This portfolio itself is built with:

- [Nuxt 4](https://nuxt.com) + [Nitro](https://nitro.build) — deployed to [Vercel](https://vercel.com) as a serverless SSR function
- [Vue 3](https://vuejs.org) Composition API
- [Nuxt UI](https://ui.nuxt.com) for pre-built, accessible components
- [TypeScript](https://www.typescriptlang.org)
- [Pinia](https://pinia.vuejs.org) for client-side UI state
- [Tailwind CSS v4](https://tailwindcss.com)
- [GSAP](https://gsap.com) (Observer + ScrollToPlugin) for the fullpage-scroll and section animations
- [@nuxtjs/i18n](https://i18n.nuxtjs.org) for English/Portuguese localization with browser-language auto-detection
